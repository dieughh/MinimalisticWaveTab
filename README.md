# Minimalistic Wave Tab

Аддон PulseSync для минималистичного оформления новой страницы «Моя волна» в Яндекс Музыке.
Перенесён со старого script-аддона на TypeScript, Vite и официальный `@pulsesync/addon-sdk` 0.17.0.

Текущая версия — 2.0.0. Сохранены ID аддона, автор, изображения, диапазоны и ID всех шести настроек.
Пользовательские настройки не включаются в сборку: штатная синхронизация сохраняет существующий
`pulsesync.settings.json`. Настройки по умолчанию соответствуют старому аддону.

## Возможности

- Минималистичный плеер с регулировкой ширины и смещением кнопок.
- Открытие и закрытие колеса рекомендаций кнопкой «Настроить», с сохранением состояния.
- Масштаб, видимость и смещение волны; поддержка изображения в Lite Mode.
- Адаптация к узким окнам, изменениям размера страницы и переходам внутри приложения.
- Освобождение наблюдателей, таймеров и обработчиков при отключении; восстановление DOM и стилей.

CSS действует внутри активной страницы «Моя волна», включая обложки и canvas.
Для изменения существующего интерфейса в манифесте используется `cssScope: 'global'`;
селекторы ограничены атрибутом `data-mwt-active`, который снимается при отключении.

Нужны актуальные PulseSync и мод с поддержкой WebHost и типизированных настроек.
Сохранён диапазон версий Яндекс Музыки из старого манифеста: `^5.97.3`.

## Разработка и сборка

Node.js 20.19+ в ветке 20.x либо 22.12+, Yarn.

```sh
yarn install
yarn build
yarn test
```

Готовый аддон: `dist/496f02ef-8227-45d4-9e92-06048c8e4322/`.
В корне репозитория также опубликована готовая версия 2.0.0: `metadata.json`,
`script.js`, `script.css`, `logo.png` и `banner.png`. После изменения исходников
эти файлы нужно обновить из готовой сборки перед публикацией.
`yarn test` проверяет TypeScript, собирает аддон и запускает проверки в тестовом DOM:
настройки, canvas и Lite Mode, узкое окно, отложенное появление страницы, ограничение CSS,
навигацию, отключение и повторное включение. Это не заменяет проверку в самой Яндекс Музыке.

## Установка для разработки

В PulseSync выберите «Открыть проект» и укажите эту папку.
`yarn dev` собирает, устанавливает и обновляет аддон при изменениях;
`yarn sync` устанавливает уже готовую сборку с сохранением пользовательских настроек.

ID и каталог установки совпадают со старым аддоном. Если он установлен из магазина,
шаблон по умолчанию блокирует его перезапись. Перед намеренной заменой сохраните копию
старой папки аддона. Затем для текущего терминала PowerShell можно разрешить замену:

```powershell
$env:PULSESYNC_ALLOW_STORE_ADDON_OVERWRITE = '1'
yarn build:sync
```

При переносе исходная установленная папка не изменялась.

## Исходники

- `addon.config.mjs` — метаданные и совместимость.
- `src/main.tsx` — регистрация аддона и жизненный цикл SDK.
- `src/settings.ts` — шесть типизированных настроек.
- `src/wave-layout.ts` — компоновка, анимация, кнопка колеса и очистка.
- `src/style.css` — оформление страницы.
- `addon/` — изображения и описание для PulseSync.
- `scripts/test-addon.mjs` — проверки собранного аддона.
